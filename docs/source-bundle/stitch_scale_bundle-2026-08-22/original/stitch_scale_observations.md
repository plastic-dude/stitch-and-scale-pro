Stitch & Scale live app observations (Aug 21, 2026)

URL: https://stitch-and-scale-pro-api-server.vercel.app/

Landing page:
- Product title: Stitch & Scale.
- Positioning: Professional knitwear grading software for designers.
- Claims: local-first, works offline, data belongs to user/export anytime, publish-ready PDF exports with four professional templates.
- Cloud sync optional / on the way; current app warns that clearing browser data deletes projects, so users should back up.
- Main actions: Draft a New Pattern; Import from a Spreadsheet; restore a backup from JSON.
- Navigation: Projects, Portfolio, Settings, New Project.

Onboarding:
- Principles: Local First, Optional Cloud Sync, Your Data, Transparent Math / visible calculations and no hidden AI decisions.
- Sizing Standard step: Craft Yarn Council (CYC) US standard selected by default; Custom Standard option; more standards available.
- Measurement units step: inches or centimeters.

Initial assessment:
- Clear product for a specific professional niche: independent knitwear designers.
- Strong differentiators for privacy/offline/ownership and transparent grading math.
- Need to inspect the core project workflow, outputs, import path, and portfolio/PDF functionality before assessing value and usability fully.

Further workflow observations:

The app describes five concepts: Dashboard for patterns; Sections for parts such as Body, Sleeve, Collar; Measurements with grading keys; Preview showing the full graded table across nine sizes; and Export producing a print-ready PDF in one of four templates.

The onboarding includes a complete sample project, Classic Crew Neck Sweater, with 3 sections, 8 measurements, Size M base, and gauge of 20 stitches / 28 rows per 4 inches in worsted weight. Users can open the sample or create their own. This is a strong demo tactic because it lets a designer inspect a real grading table before investing setup effort.

Core product observations:

The full grading table shows nine sizes (XS through 5XL), body/sleeve/neckline sections, measurements, stitch counts, row counts, exact or rounded values, and measurement-reference diagrams. It offers Copy TSV, CSV, and Print Sheet actions.

PDF export supports four templates: Minimal, Luxury, Craft / Cozy, and Technical / Blueprint. It supports logo upload, cover/gauge-summary/pattern-notes inclusion toggles, remembered filenames, and a six-page live preview. Export requires the browser print dialog to finish saving as PDF.

New project flow begins with a three-step form. Step 1 asks for Pattern Name and Designer, while the sizing standard is inherited from Settings. The flow appears intentionally lightweight but still requires the user to know grading concepts and measurements.

Portfolio page positions the product as a business operating tool, not only a grading calculator. It includes item type, skill level, market target, hours per pattern, hourly rate, launch price, launch-readiness ranking, net per-unit estimates, bundle candidates, and a one-release-per-month working rhythm. The sample catalogue contains two ready-to-launch patterns with $18 catalogue value and recommended launch prices of $10 and $8.

Potential concern: the project editor exposes a very large number of tabs (Sections, Preview, Yarn, Notes, Income, Draft, Pricing, Publish, Test Knit, Tech Edit, Finish, Deals, Launch, Trunk Show, Trans & Bundle, Pattern Club, Kits, Pipeline, KAL & Collab, Channels, Club Rev, Wholesale & Book, and many Labs). This breadth may be valuable for advanced designers but risks overwhelming new users and diluting the core value proposition.

Commercial workflow observations:

Pricing Advisor: accepts item type, skill level, market position, current price, hours worked, hourly rate, and whether tech-edited or test-knitted. The sample recommends $10, reports a $3.33 cost-plus floor, and documents conservative/market/premium bands. It compares net revenue across Ravelry, Etsy, Ribblr, and Payhip at 25, 100, and 500 sales.

Income Planner: accepts pattern price, monthly sales, design hours, hourly rate, and platform. Sample defaults of $8 price, 15 sales/month, 20 hours, and $25/hour produce $109.80 monthly net on Ravelry, 69 sales to recover design time, and $1,317.60 annualized net. It compares effective fees across Ravelry, Ribblr, Payhip, and Etsy.

Publish tab: automated pre-publish checklist reports 0 errors, 2 warnings, and 13 checks. It flags a possible unit/fit issue for the sample's 26.5-inch back length versus a standard midpoint, and warns that hip is missing for buyer size selection. It reports a 92/100 credibility score and estimates 2,624 yards. It generates marketplace listing copy from project data and provides a copyable credibility statement.

External market signals:

Search results identify existing adjacent tools and workflows, including EnvisioKnit Design Studio, Stitchmastery/chart makers, Garment Designer, spreadsheet-based grading workflows, and professional knitwear grading/tech-editing services. This indicates a real category and existing alternatives rather than a purely invented problem.
