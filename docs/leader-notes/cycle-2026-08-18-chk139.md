## Honest limits (for Reviewer/QA)
1. `0 measurements` under each section name is still English — a one-word chip
   alongside the user-entered section name. Deliberately not touched in this commit
   because it is a separate defect class (a `measurementsLabel` helper); it is now
   registered rather than silently deferred.
2. Toast/snackbar strings remain English (e.g. `Section deleted — If that was a
   misclick, it is saved in your last export.`) — lives in the shared snack/toast
   component; next-cycle item.
3. The bundle planner's intro paragraph ("The two channels every designer underuses…")
   is a long-form design narrative, not a UI control — the same class as the lab
   intros; consistent treatment belongs to a dedicated long-form localization cycle.
4. The patch-script saga: a non-greedy regex over a **single-line** file structure
   repeatedly hit because verdict-ready template literals contain commas; three
   `git restore` cycles were needed. The working fix operates per line with a full
   unique anchor (`verdictReady` value ending at `sizesGraded`). Future bulk patches
   should prefer this line+full-anchor approach, or better, a small AST script.
