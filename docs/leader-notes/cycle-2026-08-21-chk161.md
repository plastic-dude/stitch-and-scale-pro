## Problem Statement (QUEUE-017-TXN)
MAJOR: Persistence transparency missing — Design Ledger and Submission Pipeline mutated saved state silently.
- Design Ledger: `Add design`, `Record cost`, and live-edits (status/notes) happened without feedback. Write failures were swallowed.
- Submission Pipeline: `Add call` created an unsaved draft silently. Form edits persisted without acknowledgment.
- Receipt Lab: `Delete sale` was silent.
