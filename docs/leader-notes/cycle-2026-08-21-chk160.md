## Problem Statement
Extended audit E-05 (MINOR) — error boundaries for lazy modules: blank render on module switch observed (Wholesale & Book open → blank page, recovery banner after reload). Every lazy-loaded card needs Suspense/ErrorBoundary with retry; overlaps QUEUE-010 HMR class.

## Investigation & Reproduction
1. Started dev server on port 5002.
2. Navigated to workspace, clicked "Grossiste et livre" (Wholesale & Book).
3. **Repro confirmed:** The whole page blanked and was replaced by the route-level `RouteErrorBoundary` alert with "Cannot read properties of null (reading 'useState')".
4. Root cause identified: `wholesale-book-card.tsx` was missing `import React from 'react'` (or rather `React` was not in scope for JSX transformation in the lazy module), causing a reference error during mount. While the HMR crash class was previously fixed, this specific card had a regression or missed scope.
5. Structural gap: `ProjectWorkspace.tsx` mounted labs via `LazyPanel` using only `React.Suspense`. Any failure in a lab card (like a missing import or runtime crash) bubbled up to the route level, killing the whole workspace experience.

## Implementation Details
1. **`wholesale-book-card.tsx`**: Added `import React from 'react'` to fix the immediate crash.
2. **`project-workspace.tsx`**: 
   - Implemented `LabErrorBoundary` class component (React error boundary).
   - Wrapped `LazyPanel` render in `LabErrorBoundary`.
   - Added a localized recovery UI inside the workspace (amber alert card with "Retry" button).
   - Added `import React from 'react'` to ensure scope.
3. **`workspace-copy.ts`**: Added 4 new i18n keys (`loadingLab`, `labLoadErrorTitle`, `labLoadErrorDesc`, `retry`) in all 5 locales (EN, DE, FR, ES, PT).
4. **`lab-error-boundary.test.ts`**: New regression suite verifying the boundary existence, localized wiring, and recovery actions.
