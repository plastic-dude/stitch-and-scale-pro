## What CHK-128 fixed
The 79-tab desktop strip (`hidden lg:flex`, `overflow-x-auto`) opened **centered** because the Radix `TabsList` primitive's base className carries `justify-center`. With the content (~4.7–8.1k px wide, depending on locale) centered inside the scroller and `scrollLeft = 0` at first paint, the first core tabs (Sections, Preview, Yarn) sat at negative x — clipped offscreen with only a partial label visible. QA cycle 62's geometry numbers reproduced exactly in a clean context.

Fix: `flex-start` pinned on the desktop TabsList instance in `project-workspace.tsx`. Implementation lesson documented in the code comment: **Tailwind v4 does not emit a rule for `justify-[flex-start]` / `justify-content-[flex-start]`**, and v4's file-order cascade means an equal-specificity utility on the instance can silently lose — so the fix uses an inline style, which is immune to emission order. The shared `components/ui/tabs.tsx` primitive was deliberately left untouched.
