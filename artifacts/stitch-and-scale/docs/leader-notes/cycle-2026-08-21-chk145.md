## Honest note on the user-visible "Localization Audit" title
The project title shown under the heading is **user-owned project metadata** (a name typed into the app at project creation time, stored in localStorage per project) — the app correctly renders whatever the owner named the project in the active locale. It is not an app string and cannot be "translated" by the app without overwriting the owner's own project name. Everything else the app itself draws — every tab label, card heading, button, field label, toast, flag title, and verdict — is now locale-sourced.

## What was done
Owner-visible English strings had been accumulating in the 74 business-lab card surfaces (StatBox/NumField labels, card titles, headings, descriptions, badges, notes, verdict banners, table headers) and a few page surfaces (project-workspace Stitch/Row rounding labels, grading-sheet strings). This cycle ran a machine sweep over all pages/components (`label=`, `CardTitle`, `h3`, `SelectTrigger`, `StatBox`, `aria-label`, badge/verdict literals), producing an inventory of 123 bare-English findings grouped by component family.

Fixes landed in **two waves**:
1. **Existing-module extensions** — yarn-buy, translation-bundle, testknit-desk, deals-tab and other cards already had copy modules; missing keys (placeholders, badges, notes, verdict prose, table headers) were hand-added in de/fr/es/pt and wired.
2. **New shared module `lab-stat-copy.ts`** — ~260 keys covering the 25+ lab cards sharing the StatBox/NumField/heading/badge vocabulary, plus 4 new purpose-built modules (`preorder-campaign-copy.ts`, `wholesale-book-copy.ts`, `yarn-buy-copy.ts`, `yarn-estimator-copy.ts`). Cards wired via `useSettings()` → `getLabStatCopy(language)`; prose verdicts/notes stay pure in the libs and the cards map them to localized keys.
