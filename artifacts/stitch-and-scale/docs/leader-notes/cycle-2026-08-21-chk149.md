# CHK-149 — Onboarding Truth Audit (2026-08-21)

## Trigger
Owner request, 2026-08-21: the onboarding overlay has not been updated to match the current app state. Onboarding must never feel stressful or do too much, but it must not mislead. Also check "How it works" and everything else.

## Method
1. Crawled all 7 onboarding steps from `src/pages/onboarding.tsx` and extracted every user-visible string from `src/lib/i18n.ts` (all 5 locales: en/de/fr/es/pt).
2. Verified every claim against the actual code (app truth): `ALL_SIZES` (9 sizes XS–5XL), `THEMES` in `lib/pdf/themes.ts` (4 templates), the crew-neck sample in `sample-projects.ts` (3 sections, **11** measurements, gauge 20/28 per 4in, base M — plus the seeded beanie), workspace shell (77+ labs), Settings restart key, install banner copy, sizing-standards "Coming soon" list.
3. Classified each claim: FINE / STALE / MISLEADING. Only MISLEADING or factually wrong strings were changed. Verified claims were left untouched.
