# CHK-130 — Mobile All Labs Sheet closes after selection

## Scope

This cycle worked exactly one existing Reviewer/QA defect: GitHub issue #69 from QA cycle 65, a MINOR mobile navigation defect. The All Labs Sheet remained open after a lab selection, leaving its modal overlay above the newly selected panel.

## Diagnosis and fix

`TabNavigator` used the Sheet primitive without controlled open state. Its selection handler forwarded the tab value but did not close the Sheet. CHK-130 added controlled `isSheetOpen` state and closes it after `onTabChange(value)`. Calculation behavior and registry contents were unchanged.

## Regression coverage

`src/tab-navigator-sheet.test.ts` pins the controlled Sheet contract, verifies selection happens before closing, and verifies registry entries remain wired to the shared handler.
