## Fix
**Grading Print Sheet print-contrast defect** (found by the delegated #13 spot-check; fixed in `0073ac1`).

Tailwind v4 `print:` color utilities were outranked in the cascade by screen styles, so the printed grading sheet rendered faint light-gray text on cream backgrounds — present but unreadable. Fix: the sheet root carries a stable `id="sas-print-sheet"` and a scoped `@media print` stylesheet forces white background + black text + gray borders across every descendant via id selector + `!important`; the base-size header badge keeps inverted emphasis; the Print Sheet button is excluded from print output; @page landscape, shell hiding, break avoidance preserved.

Files: `artifacts/stitch-and-scale/src/pages/project-grading.tsx`, new
`artifacts/stitch-and-scale/src/grading-print-sheet.test.ts` (5 structural
regression tests pinning the print-contrast contract).

**Methodology note for the team:** Chromium headless `--print-to-pdf` does NOT
render `@media print` color rules (verified with a minimal repro). The reliable
human-substitute for print color/contrast verification is print-media
emulation (`page.emulateMediaType('print')` + `page.screenshot()` /
`getComputedStyle`). The Puppeteer script lives at `/home/ubuntu/print-emulate.mjs`
in the sandbox and is reusable for any future print-surface audit.
