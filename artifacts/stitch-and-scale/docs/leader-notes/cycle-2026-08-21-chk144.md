## What was changed
1. **`src/lib/grading-lab.ts`** — new `LabFlagCode 'G-09'` (integrity: impossible base value). New `invalidMeasurements()` helper. `analyzeGrading()` now checks every measurement up front: any non-finite or `<= 0` `baseValue` makes the verdict `blocked` with a G-09 `error` flag, zero graded sizes, and a reason string — the lab can no longer bless corrupt data.
2. **`src/pages/project-workspace.tsx`** — `handleAddMeasurement` now parses the base value and rejects anything non-finite or `<= 0` *before* persisting, with a localized destructive toast (`toast-copy.ts` key `invalidMeasurementValue(label, raw)`). The coerced `|| 0` fallback was removed so an invalid input can never silently become `0`.
3. **`src/lib/csv-import.ts`** — the import validator now rejects zero, negative, and non-finite base values (previously NaN-only).
4. **`src/lib/toast-copy.ts`** — new key `invalidMeasurementValue(label, raw)` in the interface and all 5 locales (en/de/fr/es/pt). (An earlier pass had added the key to the wrong module, `workspace-copy.ts`; it was removed there — no leftover keys.)
5. **`src/lib/grading-copy.ts`** — G-09 title added to `flagTitles` and detail entries added to `FLAG_DETAILS` for all 5 locales. Unused placeholder keys added in an earlier pass were removed so the interface stays minimal.
