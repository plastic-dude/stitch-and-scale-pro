# Cycle Log — CHK-157 (QUEUE-015-PWA)

## Mandate
Fix PWA manifest routing broken in production. Live `/manifest.webmanifest` was returning the SPA HTML shell (HTTP 200) instead of the manifest JSON, breaking install prompts on browsers that request the `.webmanifest` extension.

## Changes

### 1. `vercel.json`
- Added explicit rewrite rules for PWA-related files:
  - `/manifest.webmanifest` → `/manifest.webmanifest`
  - `/manifest.json` → `/manifest.json`
  - `/sw.js` → `/sw.js`
- These rules ensure that these files are served directly from the public directory and are not hijacked by the SPA catch-all rewrite (`/(.*)` → `/index.html`).

### 2. `artifacts/stitch-and-scale/src/pwa-routing.test.ts` (New)
- Added regression tests to:
  - Verify that `vercel.json` contains the required explicit rewrites.
  - Ensure the rewrites for manifest files appear BEFORE the SPA catch-all rule.
  - Verify that the manifest files actually exist in the `public/` directory.
