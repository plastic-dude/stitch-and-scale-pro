## What CHK-127 fixed (two defects, one commit, single highest-severity item)

### Defect A — navigator inside hidden TabsList (QA #64)
The `lg:hidden` mobile tab navigator was rendered as a **child** of the desktop strip's `<TabsList className="hidden lg:flex">`. A child of a `hidden` element can never measure or render, so the navigator was invisible below 1024px. The regression guard in CHK-125 asserted the wrapper existed but not its ancestry — that is why the defect survived CHK-120/123/125.

Fix: moved the navigator div out of the TabsList to sit directly before it, preserving the `lg:hidden` wrapper. New ancestry guard in `tab-visibility.test.ts` (DOM-free, fs-based per convention): strips JSX comments before anchoring, then asserts no `lg:hidden` navigator descendant inside any `hidden lg:flex` TabsList.

### Defect B — skip-onboarding dropped the requested deep link (found during acceptance)
In a clean context at 360px/390px/430px/768px, skipping the first-launch overlay on the demo deep link `/project/mss5osqd88j6fdyvtdu` landed on `/project/new` instead: the demo project seeds synchronously in ProjectsContext, so `hasProject` was already `true` and the else branch rerouted. The visitor who opened the demo link never saw the demo.

Fix (`src/pages/onboarding.tsx`): the overlay now captures its entry route on mount (`useState(() => location)`) and skip returns the visitor to that same `/project/:id`; only a plain root entry falls back to `/project/new`. Empty-workspace seeding is preserved so skip always ends somewhere live (the original FIX #33 contract).
